# Portfólio Profissional - Antonio Neto

## Sobre o Projeto

Apresentando experiência profissional, formação acadêmica, projetos e habilidades técnicas. O site foi desenvolvido com foco em design moderno, responsivo e com animações suaves para proporcionar uma excelente experiência ao usuário.

## Tecnologias Utilizadas

### Core

- **React** 18.3.1 - Biblioteca JavaScript para construção de interfaces
- **TypeScript** - Superset JavaScript com tipagem estática
- **Vite** - Build tool e dev server de alta performance
- **React Router DOM** 6.30.1 - Roteamento de páginas

### UI/UX

- **Tailwind CSS** - Framework CSS utility-first
- **shadcn/ui** - Componentes React acessíveis e customizáveis
- **Framer Motion** 12.23.24 - Biblioteca de animações
- **Lucide React** 0.462.0 - Ícones modernos

### Componentes Radix UI

- Accordion, Dialog, Dropdown Menu, Tooltip
- Avatar, Badge, Button, Card
- Tabs, Select, Popover
- E muitos outros componentes acessíveis

### Formulários e Validação

- **React Hook Form** 7.61.1 - Gerenciamento de formulários
- **Zod** 3.25.76 - Validação de schemas
- **@hookform/resolvers** 3.10.0 - Integração entre validadores

### Gerenciamento de Estado

- **TanStack Query** 5.83.0 - Gerenciamento de estado assíncrono

### Outros

- **Sonner** - Toast notifications
- **date-fns** - Manipulação de datas
- **embla-carousel-react** - Carrosséis
- **recharts** - Gráficos e visualizações
- **next-themes** - Gerenciamento de tema (dark/light mode)

## Estrutura do Projeto

```
src/
├── components/       # Componentes reutilizáveis
│   ├── ui/          # Componentes shadcn/ui
│   └── ...          # Componentes customizados
├── pages/           # Páginas da aplicação
├── hooks/           # React hooks customizados
├── lib/             # Utilitários e configurações
└── main.tsx         # Entry point da aplicação
```
